
# QuranProject - VlogNest Creator Studio

This project is a high-performance content management and spiritual reflection platform.

## Git Setup Instructions

To upload this project to your `quranproject` repository:

1.  **Initialize Git**: 
    ```bash
    git init
    ```
2.  **Add your files**: 
    ```bash
    git add .
    ```
3.  **Commit the changes**: 
    ```bash
    git commit -m "Initial commit: Setup monochromatic UI and deep sync"
    ```
4.  **Connect to your repository**:
    *(Replace `<URL>` with your actual repository URL)*
    ```bash
    git remote add origin <URL>
    ```
5.  **Push to main**:
    ```bash
    git branch -M main
    git push -u origin main
    ```

## Development

Run the development server:
```bash
npm run dev
```
